# SE Practical / Oral – draw.io exam pack

Editable draw.io diagrams and numericals for the 20 Software Engineering practical questions.

## How to use
1. Download a file from `drawio/` (or clone the repo).
2. Open it in [draw.io](https://app.diagrams.net) (File → Open from → Device), or drag it into the window.
3. To copy into your own diagram: Ctrl+A, Ctrl+C, then Ctrl+V in your file.

Most files have one tab per source PDF (CJ and Practical). Where the two PDFs differ, pick the tab you need.

For the DFD questions (Q7, Q16, Q17) each tab holds **Level 0 and Level 1 together on one page**, so a single Ctrl+A copy gets both levels.

## Folders
- `drawio/` – one `.drawio` file per question
- `pdfs/` – the source PDFs (`SE-PRAC-ANS-CJ.pdf`, `SE-Practical.pdf`)
